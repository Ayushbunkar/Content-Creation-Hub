# LOCAL AI VIDEO STUDIO — Asset Licenses & Attributions

This project uses exclusively open-source, public domain, and permissible assets for all offline and local operations.

---

## 1. Cartography & Map Data
- **Natural Earth**: Public Domain. All vector boundaries, landmass polygons, and coastline coordinates used in the animated map visual engine are derived from Natural Earth datasets (1:50m and 1:110m cultural vectors).
- **SVG Path Projections**: Generated procedurally and rendered using native React vector elements without proprietary map SDKs or external tile server dependencies.

---

## 2. Audio & Speech
- **Kokoro-82M**: Apache 2.0 license. Lightweight, high-quality open-source text-to-speech model developed by Hexgrad. Runs 100% locally on CPU.
- **OpenAI Whisper (Base)**: MIT license. Open-source automatic speech recognition engine running locally on CPU.
- **Synthesized Ambient Music**: Generated procedurally and royalty-free for offline documentary background accompaniment.

---

## 3. Fonts & Typography
- **Inter**: SIL Open Font License (OFL) 1.1. Modern documentary interface and kinetic subtitle typeface.
- **JetBrains Mono**: Apache 2.0. Clean monospaced typeface for technical statistics and data badges.
- **Playfair Display**: SIL Open Font License (OFL) 1.1. Editorial serif typeface for historical and crime mystery titles.
